# Clase 32 — Maven (y Gradle)

**BLOQUE 5 — Bases de datos, JDBC y build tools (clases 28–34)**

- **Maven**: qué es (gestor de dependencias + automatizador de build). `pom.xml`, coordenadas GAV, scopes, ciclo de vida (`validate → compile → test → package → verify → install → deploy`), plugins, repositorio local `.m2`, dependencias transitivas y conflictos.
- **Gradle**: qué es (lo mismo pero con DSL en Groovy/Kotlin en vez de XML, builds incrementales, más rápido y más flexible).
- **Cuál usar:** Maven domina en empresas con Spring Boot y backend corporativo; Gradle domina en Android y proyectos grandes. Aprendés Maven a fondo y Gradle lo suficiente para leerlo.
