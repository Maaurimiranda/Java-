# Clase 46 — Testing: unit tests

**BLOQUE 6 — Spring Boot y desarrollo backend (clases 35–50)**

- JUnit 5: `@Test`, `@BeforeEach`, `@ParameterizedTest`, `@Nested`, `@DisplayName`, assertions.
- **Mockito**: `@Mock`, `@InjectMocks`, `when/thenReturn`, `verify`, `ArgumentCaptor`, `doThrow`.
- Qué mockear y qué no. Test doubles: mock vs stub vs spy vs fake.
- AssertJ para assertions legibles.
- Patrón AAA (Arrange-Act-Assert), un assert conceptual por test.
