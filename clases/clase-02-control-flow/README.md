# Clase 2 — Control flow

**BLOQUE 1 — Fundamentos (clases 1–8)**

- `if/else if/else`, `switch` clásico y `switch` expression (Java 14+, con `->` y `yield`).
- `for`, `for-each`, `while`, `do-while`. Cuándo usar cada uno.
- `break`, `continue`, labeled breaks (y por qué casi nunca los uses).
- Bucles anidados.

**Ejercicios:** FizzBuzz, número primo, tabla de multiplicar formateada, pirámides de asteriscos, adivinanza con intentos limitados.
