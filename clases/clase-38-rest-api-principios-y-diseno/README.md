# Clase 38 — REST API: principios y diseño

**BLOQUE 6 — Spring Boot y desarrollo backend (clases 35–50)**

- **Principios RESTful**: stateless, recursos identificados por URI, representaciones, HATEOAS (y por qué casi nadie lo usa), idempotencia.
- Verbos: GET, POST, PUT, PATCH, DELETE — semántica e idempotencia de cada uno.
- Diseño de URIs: sustantivos en plural, jerarquías, nada de verbos en la URL.
- Status codes correctos: 200/201/204/400/401/403/404/409/422/500.
- Versionado, paginación, filtrado, ordenamiento.
- **Buenas prácticas** y errores típicos.
