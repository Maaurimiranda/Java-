# Clase 50 — PROYECTO 6: Product API completa (Authentication + Product)

**BLOQUE 6 — Spring Boot y desarrollo backend (clases 35–50)**

La API que va a ir a tu portfolio como pieza central.

**Requisitos:**

- CRUD de productos con categorías, búsqueda, filtros y paginación.

- Tests: >70% de cobertura, unitarios con Mockito + integración con Testcontainers.
- Documentación OpenAPI.
