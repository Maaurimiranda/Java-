# Clase 5 — Strings

**BLOQUE 1 — Fundamentos (clases 1–8)**

- Inmutabilidad y el string pool. `==` vs `.equals()` (clásico de entrevista).
- Métodos: `substring`, `indexOf`, `split`, `trim`, `replace`, `charAt`, `toCharArray`, `format`.
- `StringBuilder` vs `String` en bucles (medí la diferencia con `System.nanoTime()`).
- Text blocks (`"""`).
